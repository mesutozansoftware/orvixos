OrvixOS paket deposu

OrvixOS'ta kurmak için komutu yaz; başka bir Debian tabanlı sistemde .deb dosyasını indirip vpx install ./dosya.deb ya da sudo apt install ./dosya.deb ile kur. Depo imzalıdır.
